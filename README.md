# Project Learning Notes

> 把项目源码转化为可持续生长的学习系统：有路径、有进度，也不会遗失每一次提问。

学习代码时，真正难的不是看懂某个文件，而是把零散理解组织成可复用的知识。本 skill 会先读取项目结构与源码，再持续维护三份与代码绑定的学习资产：章节笔记、学习进度和项目记忆。

## 它解决什么问题

| 场景 | 结果 |
| --- | --- |
| 接手一个陌生项目 | 生成基于真实文件的章节地图与学习顺序 |
| 学到一半忘了进度 | 维护当前章节、掌握状态和下一步行动 |
| 针对某章向 Agent 提问 | 先回答，再自动将问答沉淀到对应章节 |
| 多次学习同一项目 | 用 `AGENTS.md` 保留规则，避免知识库断档 |

## 使用方式

将本仓库克隆到 Codex skills 目录：

```powershell
git clone git@github.com:kklay11/-.skill.git "$env:USERPROFILE\.codex\skills\project-learning-notes"
```

重新打开 Codex 会话后，直接提出任务：

```text
使用 $project-learning-notes 阅读当前项目，建立中文学习笔记和进度文档。
```

之后正常学习即可：

```text
第二章的请求体为什么不在 URL 中？
```

Agent 会基于章节源码回答，并把问题和答案写入该章节的 `Q&A`；需要时同步更新学习进度与更新日志。

## 产出结构

```text
your-project/
├── AGENTS.md                     # 项目记忆：章节提问必须自动沉淀
└── docs/
    ├── <project>-study-notes.md  # 章节笔记与 Q&A
    └── learning-progress.md      # 路线、进度、下一步与更新日志
```

如果项目已有同类文档，skill 会继续维护原文件，而不是创建重复副本。

## 工作闭环

```text
读取源码 → 归类章节 → 生成笔记与进度 → 学习者提问 → 基于代码回答 → Q&A 写回文档 → 更新下一步
```

这不是一次性的文档生成器。它将问题、答案和项目代码保持在同一个学习闭环中，让下一次继续学习时有可靠的上下文。
