# 📚 learn.skill（学习.skill）

**让任意 Agent 读懂你的项目，并把每一次学习沉淀为可继续的知识。**

`读源码` · `建章节` · `追进度` · `存问答`

</div>

> 教程会过期，聊天记录会淹没，源码才是项目最可靠的教材。

`学习.skill` 从真实代码出发，自动建立笔记、学习进度和问题库。你只管学习，Agent 负责让理解持续积累。

## 30 秒开始

将本目录交给正在使用的 Agent，然后说：

```text
读取当前项目，按源码建立中文学习笔记和学习进度。
```

之后可以像平时一样提问：

```text
第二章的请求体为什么不在 URL 中？
```

Agent 会先结合代码回答，再自动将问题和答案写回对应章节。下一次继续学习时，进度和问题都还在。

## 它不是“生成一篇笔记”

| 你遇到的情况 | 学习.skill 的处理 |
| --- | --- |
| 刚接手陌生项目 | 读取目录与源码，梳理出可学习的章节顺序 |
| 不知道从哪里继续 | 写清当前进度、掌握情况和唯一下一步 |
| 某段代码始终想不通 | 基于相关源码回答，不凭空编造 |
| 问过的问题又忘了 | 将问题与最终答案写回该章节的 `Q&A` |
| 换了 Agent 或新开会话 | 复用项目内的笔记、进度和记忆规则 |

## 学习闭环

```text
源码
  ↓
章节地图 → 学习笔记 → 你的问题 → 代码依据的回答
  ↑                                      ↓
学习进度 ← 下一步行动 ← 写回章节 Q&A
```

每个环节都落在项目文件中，而不是某个会话里。

## 产出什么

```text
your-project/
└── docs/
    ├── <project>-study-notes.md  # 章节、代码索引、要点与 Q&A
    ├── learning-progress.md      # 当前进度、路线图、下一步、更新日志
    └── learning-memory.md        # 不支持项目记忆的 Agent 的可移植规则
```

如果 Agent 支持项目级说明或记忆文件，skill 会优先将“章节提问后自动沉淀”的规则写入该文件；否则使用 `docs/learning-memory.md`。已有学习文档会被持续维护，不会重复创建。

## 适用场景

- 跟着源码学习 Web、后端、前端、脚本或数据项目
- 把练习项目整理成可复盘的学习记录
- 从零理解团队项目，而非只获得一次性讲解
- 使用不同 Agent 协作，但希望学习上下文持续存在

## 设计原则

1. **以源码为准**：每个章节都能追溯到实际文件。
2. **问答必须落盘**：回答完才算完成，避免相同问题反复出现。
3. **进度如实记录**：文件存在不等于已经掌握。
4. **不绑定工具**：任何能读取 `SKILL.md` 并操作项目文件的 Agent 都可以执行。

## 使用这个 skill

将 `SKILL.md` 放入或加载到你的 Agent 的 skills 目录，再使用下面的提示开始：

```text
使用学习.skill 阅读当前项目；生成学习笔记、进度文档，并把章节问题自动沉淀到对应 Q&A。
```

这是一套可持续的学习工作流，不是一篇会被遗忘的总结。
